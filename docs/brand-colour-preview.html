Usage Rules

01
Blue is the only interactive colour. Every button, link, and toggle uses #2563EB. Nothing else.
02
Never use blue for decorative text. Blue belongs to interactive elements only — not headings, not backgrounds.
03
Green and red are data, not brand. They appear only in P&L rows and status badges — never in navigation or brand contexts.
04
Blue stays the same in both themes. #2563EB is the anchor. Background and text flip — blue never moves.
05
One blue hero per view. Don't stack blue elements competing for attention. One primary action per screen.
